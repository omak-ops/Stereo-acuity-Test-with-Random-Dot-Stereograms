  1. Set the display to 1:1 so one image pixel is one screen pixel (see the display check above), set browser zoom to 100%, brightness to full, and turn off True Tone and Night Shift (System Settings › Displays) so red and cyan stay pure.
  2. Seat the participant 50 cm from the screen, eyes level with its centre, and put the glasses on with the red lens over the left eye.
  3. Tell them the answer options: circle, triangle, star, heart, cross, or nothing. Give them as long as they need on each image.
  4. Run the practice, then the test. Type the key for what they say; the screen gives no feedback in the test. Then run the control without glasses. A stopped block can be resumed where it stopped.
